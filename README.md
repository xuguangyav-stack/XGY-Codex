# 个人资产管理工具

一个无需后端、开箱即用的个人资产管理单页工具，适合快速记录资产、负债、收支流水与财务目标。

## 功能亮点

- **资产/负债管理**：支持录入账户名称、资产类型、分类与当前余额。
- **收支流水记录**：支持记录收入与支出，并自动计算本月结余。
- **净资产概览**：自动汇总总资产、总负债与净资产。
- **财务目标追踪**：支持设置目标金额、当前进度与截止日期。
- **资产配置分析**：自动展示资产分类占比。
- **智能建议**：基于已录入数据给出储蓄率、应急金、负债与目标方面的提示。
- **本地持久化**：使用浏览器 `localStorage` 自动保存，无需登录。

## 使用方式

直接在浏览器打开 `index.html` 即可使用。

如果你想本地启动一个静态服务，可以执行：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 文件说明

- `index.html`：页面结构。
- `styles.css`：界面样式。
- `app.js`：数据逻辑、渲染和本地存储。
